Node WebOS × Browser

This extension does two things: it can replace your new-tab page with Node, and it can copy the cookies Brave/Chromium already holds for your LMS and mail providers into your own server so server-side sessions stop expiring. Cookie data is only ever sent to the server URL below.

Server
Loopback, Tailscale (100.x.y.z), or another private address. Never a public host.
Node → Settings → Extension → Guard token. Required when the lock screen is on, so the new tab can still read task/urgent counts.
Session capture
Only cookies for these domains are read. Matches subdomains too (e.g. instructure.com covers canvas.instructure.com). Add any provider you use.
